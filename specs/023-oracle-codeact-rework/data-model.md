## Entities

### 1. OracleState (LangGraph Graph State)

Extends `CodeActState` from `langgraph-codeact`. Fields added to the base state:

```python
from langgraph_codeact import CodeActState
from typing import Annotated, Any, Optional
from typing_extensions import TypedDict
import operator

class OracleState(CodeActState):
    # Inherited from CodeActState:
    #   messages: list[BaseMessage]   — full conversation history
    #   context: dict[str, Any]       — REPL variable namespace (checkpointed)

    # Project/user scoping (set at thread creation, never changes)
    user_id: str
    project_id: str

    # Planner output (mutable during execution)
    plan: Optional[list[str]]          # decomposed task steps; None if planning was skipped
    plan_step: int                     # current step index (0-indexed)

    # Memory recall injected before agent turn
    recalled_facts: list[str]          # fact strings loaded from Graphiti at turn start

    # NOT stored here (security):
    # api_key — passed via config["configurable"]["api_key"]
    # oracle_model — passed via config["configurable"]["oracle_model"]
```

**Validation rules**:
- `user_id` and `project_id` are set once at thread creation; never mutated by graph nodes
- `plan` is `None` for simple queries (planning skipped by rule-based classifier)
- `plan_step` must be `0 <= plan_step <= len(plan)` when `plan` is not None
- `recalled_facts` is replaced each turn (not appended); max 10 facts per turn

**State transitions**:
```
Thread created → OracleState.user_id/project_id set; plan=None; recalled_facts=[]
                ↓
Turn start      → memory_loader_node: recalled_facts updated from Graphiti
                ↓
Classify        → rule-based classifier: simple → skip planner; complex → planner_node
                ↓
Plan (optional) → planner_node: plan=[...], plan_step=0
                ↓
Execute         → CodeAct agent loop: context accumulates REPL vars; plan_step increments
                ↓
Turn end        → memory_writer_node: background episode add to Graphiti; recalled_facts cleared
```

### 2. ConversationThread (oracle_threads table)

Persisted in `data/index.db` alongside existing tables. Thread listing index — LangGraph has no thread listing API.

```sql
CREATE TABLE IF NOT EXISTS oracle_threads (
    thread_id       TEXT PRIMARY KEY,
    user_id         TEXT NOT NULL,
    project_id      TEXT NOT NULL,
    title           TEXT,              -- NULL until first message; auto-derived from first user message
    created_at      TEXT NOT NULL,     -- ISO 8601 UTC (e.g. 2026-03-11T14:00:00Z)
    last_active_at  TEXT NOT NULL      -- updated on every new turn
);

CREATE INDEX IF NOT EXISTS idx_oracle_threads_user
    ON oracle_threads(user_id, last_active_at DESC);
```

**Validation rules**:
- `thread_id` is a UUID generated by the backend on thread creation
- `title` auto-derived from first user message (first 60 chars, trimmed); can be NULL if not yet set
- `last_active_at` updated atomically with the turn that modifies state
- Delete cascades: deleting a thread removes it from this table; LangGraph checkpoint entries are left for data retention (can be reaped on a schedule)

### 3. MemoryFact (Graphiti episode / edge)

Managed entirely by `graphiti-core`. Not a SQLite table — stored in FalkorDB.

**Episode (input to Graphiti)**:
```python
episode = {
    "name": str,           # e.g. "oracle-turn-{thread_id}-{turn_index}"
    "episode_body": str,   # stringified summary of what was learned this turn
    "group_id": str,       # f"{user_id}:{project_id}" for project scope
                           # f"{user_id}:_user" for user preferences
    "source": "message",   # Graphiti episode source type
    "reference_time": datetime  # turn timestamp
}
```

**Semantic search (query)**:
```python
results = await graphiti.search(
    query=str,          # semantic similarity query
    group_id=str,       # same group_id scoping as add_episode
    limit=int,          # default 10; loader uses 10
)
# Returns: list of edges with .fact (str), .valid_at, .invalid_at
```

**Temporal validity**:
- Each fact edge has `valid_at` and `invalid_at` timestamps
- When the agent discovers a fact contradicts an older one, Graphiti automatically sets `invalid_at = now` on the old edge and inserts a new edge with `valid_at = now`
- Query results only return edges where `invalid_at IS NULL` (currently valid facts)

**Scoping**:
| Scope | group_id |
|---|---|
| Project-specific facts | `f"{user_id}:{project_id}"` |
| User preferences | `f"{user_id}:_user"` |

### 5. OracleStreamChunk (existing, unchanged)

Existing Pydantic model — not modified. Documented for streaming contract reference:

```python
class OracleStreamChunk(BaseModel):
    type: Literal[
        "thinking",       # model thinking tokens
        "content",        # streamed answer text
        "source",         # source citation
        "tool_call",      # tool invocation start
        "tool_result",    # tool result
        "done",           # stream complete; context_id field set to thread_id
        "error",          # error message
        "system",         # ANS system notification
        "context_update", # context_id newly created or changed
        "progress",       # REPL stdout / step progress
    ]
    content: Optional[str] = None
    context_id: Optional[str] = None    # set on "done" chunk with thread_id value
    metadata: dict[str, Any] = {}
```

**Mapping from LangGraph `astream_events`**:

| LangGraph event | OracleStreamChunk type |
|---|---|
| `on_chat_model_stream` | `content` |
| `on_tool_start` | `tool_call` |
| `on_tool_end` | `tool_result` |
| `on_custom_event` name=`repl_stdout` | `progress` |
| graph end | `done` (context_id=thread_id) |
| exception | `error` |

### 7. LangGraph Checkpointer Config

Passed via `config["configurable"]` on every `astream_events()` / `ainvoke()` call:

```python
config = {
    "configurable": {
        "thread_id": thread_id,          # maps to oracle_threads.thread_id
        "api_key": api_key,              # NOT checkpointed — per-request only
        "oracle_model": oracle_model,    # NOT checkpointed — from user settings
    }
}
```

**Security invariant**: `api_key` and `oracle_model` are in `configurable`, which LangGraph's `AsyncSqliteSaver` does not persist. They are resolved fresh from `UserSettingsService` on every request.

## Persistence Topology

```
data/
├── index.db         ← existing; ADD oracle_threads table
└── checkpoints.db   ← new; owned by AsyncSqliteSaver (LangGraph)

FalkorDB (Docker, bolt://localhost:6379)
└── Graphiti episodes + entity graph (all users/projects scoped by group_id)
```

**Migration**: No data migration needed. Existing `oracle_bridge_history` and `context_trees` tables in `index.db` remain unchanged (read-only legacy data visible to frontend).
